# M02 阶段报告：shared ABI v11 行为等价接入

## 1. 阶段结果

M02 已将 kernel producer、shared reader、libkernel.so wrapper、功能测试和
benchmark 同步迁移到唯一 ABI v11。外部 syscall/`__vkso_*` ABI 与 MM_data
v3未改变，未保留 ABI v10 兼容分支。

本阶段只改变布局，不提前执行 M03 的 timekeeper 所有权迁移或 M05 的算法
重构。

## 2. 主要修改

- mono/raw 的相同 cycle metadata 合并为一个 32-byte descriptor；
- 保留 `mono_mult`、`raw_mult` 两个真实差异字段；
- 新增 M01 要求的 64-bit `mask`；
- 七种 global clock 的 bases、coarse、resolution 和 timezone 统一进入
  `vkso_read_state`；
- raw base独立放在 shared offset 128；
- publisher 和 reader 全部改用 v11 offset；
- concurrent test显式传入选定 multiplier offset；
- 用户测试 ABI 增加 v11 mirror layout 和静态断言；
- wrapper init同时校验 shared ABI v11 与 MM_data v3；
- benchmark seq observer同步读取单 descriptor和对应 multiplier。

完整 offset 与 memory-order 约束见 `ABI_V11.md`。

## 4. 权限与泄漏边界

最终 libkernel.so program headers：

```text
core/user text: RX
shared page:    R--
wrapper data:   RW-
```

`vkso_shared_page` 是 4096-byte object，位于独立 R-- LOAD；shared payload
只有固定宽度整数，无 pointer、lock、clocksource 或 timekeeper private 字段。
MM_data仍通过原 per-MM special mapping提供。

## 5. 代码规模纪律

产品布局从 184 bytes 降为 168 bytes，新增必要 mask 后仍净减 16 bytes。
删除了一份 raw mode/cycle_last/shift 和对应 publisher/reader选择逻辑。

本阶段 Git churn包含 ABI mirror/assert/test 更新，不能当最终产品 SLOC：

- 当前产品与测试合计：191 additions、132 deletions；
- `static_assert`、mirror test struct和 benchmark属于 T1，不进入产品 SLOC；
- compat adapter仍属 X1，只为 M02 行为等价存在，必须在 M04 删除。

没有引入 v10/v11 双路径、第二份算法或新的 fallback 分支。

## 7. 退出判断

M02 退出条件全部满足：

- ABI v11单一启用；
- 外部 ABI 与 MM_data v3不变；
- layout在 kernel/wrapper/test一致；
- normal、TIME_NS、PVClock、Hyper-V构建通过；
- QEMU功能语义与 Raw 完全一致；
- shared权限和 private隔离保持；
- 无运行时 v10兼容。

下一阶段进入 M03，把 canonical `tk_read_state` 纳入 timekeeper producer所有权，
分组消除 compat转换和双重 source-of-truth。
