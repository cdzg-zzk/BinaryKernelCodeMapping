# UPDATE 图表契约及渲染检查

输入为本目录派生 CSV，全部由正式原始样本复算。主均值图覆盖八项配置/负载对照，负载响应图覆盖六项相对 idle 对照，分解图覆盖八项四贡献恒等式。两张分布图分别展示每配置四负载、两后端、各四次启动的密度与完整 CDF。

均值和负载变化使用线性 TSC ticks 轴与零线；所有实际块值、区间均位于坐标范围内。Raw 灰圆、VKSO 蓝方用于负载响应；配置差值使用蓝圆/橙方。密度用细线保留四次启动，粗线表示等权平均，分母包含全部样本。CDF 以对数横轴覆盖最大观测。

四项分解对负贡献和正贡献保留同一零线，黑点标记总差值；条形不是分峰状态的因果成本。源码 update_report.py 固定数据映射，SVG 保留文本和矢量元素，同时输出 PDF 与 PNG。

渲染检查：初次发现分布图的负载名与密度标题重叠，已合并为一个面板标题；最终检查五张图的标签、图例、刻度、完整范围与数值映射。没有删除启动点或缩短宽区间改善外观。两个 LaTeX 文件为 booktabs 表内容片段。
