## 已回答：记录器改变后端相对比较

D = (VKSO−Raw)Current − (VKSO−Raw)Legacy，单位TSC ticks。
各启动先使用完整周期样本均值，再计算块内对照；下列平均为两块等权。
两块范围是实际观察范围，不是总体置信区间。

| 负载 | 第一块D | 第二块D | 两块等权均值 | 两块方向 |
| --- | ---: | ---: | ---: | --- |
| idle | -51.459 | -30.250 | -40.854 | 一致 |
| monotonic | +66.804 | +31.887 | +49.346 | 一致 |
| monotonic_raw | -72.785 | -53.817 | -63.301 | 一致 |
| monotonic_coarse | +43.365 | -44.996 | -0.816 | 翻转 |

idle、MONO、RAW在两块中重复了相对变化的方向。COARSE均值效应翻转，
其等权平均−0.816 ticks不能用于声称“记录器影响接近零”。
因此完整发布的后端成本差必须绑定记录器及实测启动分布，不能扣除一个公共常数还原无插桩成本。
干预包括记录器接口、主体及其引起的链接布局变化，不能仅归于参数个数或某个缓存事件。

两种记录器、两块中，idle的VKSO−Raw均值差均为正，三个读取负载均为负：
这一方向在所测条件下重复，但差值大小有记录器敏感性，不能外推到未测配置或无插桩实现。
逐记录器/逐块绝对差见[对照表](contrasts.csv)和[完整摘要](README.md)。

| 负载 | 峰位差变化：第一块/第二块（σ=3） | 最低90%对D贡献：第一块/第二块 | 最高1%对D贡献：第一块/第二块 |
| --- | --- | --- | --- |
| idle | +27 / +34 | -38.402 / -34.786 | -3.532 / -0.595 |
| monotonic | +29 / +33 | +52.752 / +23.875 | +11.120 / -0.318 |
| monotonic_raw | +56 / +57 | -66.264 / -51.519 | +7.462 / +0.622 |
| monotonic_coarse | +82 / +81 | +43.498 / -40.273 | +15.531 / -5.723 |

四负载的主峰差变化均为正，σ=2/5下方向相同；COARSE主峰差变化+82/+81与其均值方向翻转并存。
这说明汇总主峰不能替代整个分布。峰身份可能更换，峰位差不等同于同一物理状态的连续平移。
COARSE的最低90%贡献也从+43.498翻为−40.273 ticks，翻转不只由最高1%尾部造成。
分位秩分段使用各单元自己的排序，不是样本配对或物理状态归因。

共同时间区域按先导冻结，未随这次结果调整。逐区域概率、条件均值、对完整均值的贡献和四单元差中差，
分别保存在[第一块审计](../step-03-review/block-audit.json)和[第二块审计](block-audit.json)。
例如COARSE的(649,1022]占比差中差从−5.050变为+24.138个百分点，(1022,1289]从+14.225变为−5.213；
它们描述概率质量在时间区域间的变化，不把区域命名为缓存命中/缺失。差中差本身不是概率，可超出±100个百分点。
