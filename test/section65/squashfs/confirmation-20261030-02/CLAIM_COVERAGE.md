## 有限矩阵的充分性与未外推范围

- 五种 codec 的 native 功能/成本覆盖声明支持的格式；应用性能只对 gzip/XZ/LZ4 普通 SIF，以及 gzip/XZ Python SIF 作结论。lzo/zstd 应用性能未验证。
- include scan/archive 代表元数据、小文件访问；两个 128 MiB 文件的归档代表顺序和不同可压缩性；Python 编译涵盖现有不同程序/文件树。此次优化使用了 Python 结果，所以不再称未见过的独立确认任务。
- 三轮 campaign 使用新进程、挂载或加载周期，内部交错配对；同一主机/启动不替代跨机器或跨启动复现。每格区间以三个 campaign 为独立统计单位，不以全部访问条数为样本数。
- 边界/随机 offset 是正确性检查；消费者同时存活是状态/生命周期检查。没有随机 I/O 吞吐、并发扩展、多进程内存阶梯或自动热修复主张。
- 本轮全部最终桥应用重测；只复用四个 native campaign（2688条），其 owner、consumer、runner、环境身份在注册和审计中核验。中断组790条全部保留但排除，以原参数整组替代。
- 完成条件是固定30组8172条、所有正确性与独立数据审计通过、源码/日志/失败记录保留、报告和清理完成。未证明的工时和整机收益不会通过删除或改称“已支付”来成立。

历史 `PROTOCOL.md` 的7692条是“桥不改变”的初始方案；新增直接旧桥对照且全部用户侧重测后的冻结方案以 `CACHE_PROTOCOL.md`、`SELECTION.md`、`registration.json` 及仅恢复名称变化的 `recovered-registration.json` 为准。正文和绘图按用户新要求延期，不属于本轮完成条件。
