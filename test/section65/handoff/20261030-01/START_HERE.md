# VKSO Section 6.5 交接包

这是 2026-10-30 的核心源码与证据包。下一任务是**优化公共 XZ 的应用回退和私有缓存增长**，不是重新整理已有结果或继续无边界扩大实验。

1. 将 `HANDOFF_PROMPT.md`（或内容相同的 `.txt`）完整复制给接手 LLM。
2. 同时提供本包；若接手者能访问原工作区，说明仓库是 `/home/zzk/BinaryKernelCodeMapping`。
3. 让其按 prompt 的阅读顺序先核对版本，再推进有限诊断和实现优化。

`repo/` 保留原仓库相对路径。`CORE_FILES.md` 是定向入口。
`BUNDLE_MANIFEST.json` 含每个打包文件的字节数和 SHA-256；归档旁的
`.zip.sha256` 校验整个 ZIP。`verified-baseline.json` 是打包前重新通过的
现有最终版本检查，不代表接下来要做的优化已经完成。

已包括：

- 核心准备、用户桥、FUSE、导出与注册支持源码；当前及前版的关键构建和最终源码冻结。
- 当前 30 个完整 campaign 的全部 6,540 条计时样本、环境/顺序记录、PFN、资源与主要日志。
- 28 条中断样本和恢复记录；重要功能、维护、调试、诊断和失败记录。
- 现有分析脚本、汇总、成本账本、图表、4 页正文 + 附录的 PDF，以及前版出版归档。
- 输入镜像构建清单、版本与配置、复现说明和完整交接 prompt。

没有包括完整 Linux/LKL 构建树、SIF/SquashFS 镜像、VM 磁盘/initramfs、
Apptainer 安装或 Python 工具环境，因此本包不是解压即可运行的完整实验环境。
大型逐文件 native/oracle 清单也不随核心包发送，路径/大小/哈希另列。
这些材料的位置和已有身份清单见 `EXTERNAL_ASSETS.json`。完整运行资产仍在原工作区。

包不含账户密码、私有凭据或无关的用户配置。模块和二进制是特定研究内核的评估产物；
接手者必须核对当前内核/资产身份，不能把归档直接装载到不匹配的机器上。

重要版本边界：上一版用户 XZ 使用 liblzma，xz 顺序回退约 5%；本版真正共用
内核 XZ，xz 顺序回退 13.10%，独立 Python 编译在 xz 镜像中回退 16.18%。
后两项均对默认 SquashFUSE，不是 copied/shared 增量。原因只定位到执行路径切换，
具体热点尚待查明；不能把猜测写成已经确认的根因。
